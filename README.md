# Simplefetch

Simplefetch is a simple neofetch-like command tool for Linux.
It is implemented in the C language.

## The Project

Simplefetch is a learning project for myself to get into C programming.
So feel free to download the repo and to make suggestions about what i can do better :)

## Using Simplefetch

To build, execute:

```./scripts/build```

To run Simplefetch, execute:
```./build/simplefetch```
